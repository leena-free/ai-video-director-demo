# AI 视频导演台 · 演示版

把一段大白话，变成 AI 视频工具可用的分镜 Prompt。

在线演示：https://leena-free.github.io/ai-video-director-demo/

## 功能

- 输入正常语言，自动拆成「钩子 → 痛点 → 转折 → 价值 → 收尾」
- 输出口播脚本、逐镜分镜、中文 Prompt、English Prompt、负向约束
- 内置 5 类叙事模型和 50 个可组合镜头
- 「复制豆包整包」和「复制纯 Prompt」，直接粘到豆包或其它视频工具
- 角色资产、定妆图 Prompt、发布标题、合规体检
- 全程浏览器本地运行，不上传内容

## 使用

1. 打开在线演示
2. 输入你想拍的事：给谁看、遇到什么难处、想表达什么、时长、平台
3. 点「生成分镜与提示词」
4. 在「分镜 Prompt」页复制豆包整包或纯 Prompt
5. 到豆包 / 即梦 / 可灵 / 海螺 / Runway / Veo / Sora 生成，后期拼接
